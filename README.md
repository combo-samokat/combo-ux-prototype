# Комбо от 2 до 5

Статический прототип для UX-исследования.

- `index.html` — первая страница с карточкой комбо.
- `combo.html` — вариант A: смена цифр цены.
- `combo-roll.html` — вариант B: прокрутка цифр цены.
- `success.html` и `success-roll.html` — целевые страницы исследования.

GitHub Pages: Deploy from a branch → main → / (root).
